# CutPot 0.8.1 · macOS / Windows 安装包

将整个 CutPot 文件夹解压到另一台电脑的固定位置（建议“文稿”或 D:\Apps），**先完整解压再运行，不要在 ZIP 内直接运行，也不要只复制启动文件**。本包是本机网页工作台 + CLI 安装包，不是独立的 .app / .exe。首次配置依赖需要联网；本机剪辑和导出可以离线运行。

## macOS（Apple Silicon / Intel）

1. 双击 `安装-macOS.command`。脚本检查 Node.js 22+、FFmpeg / ffprobe、Python，并在隔离环境安装字幕依赖 Pillow；缺依赖且有 Homebrew 时通过 Homebrew 安装。
2. 如果提示没有 Homebrew，按提示从 https://brew.sh 安装，或自行安装 Node.js / FFmpeg / Python 后再运行安装入口。安装系统依赖时可能要求系统密码。
3. 双击 `启动-macOS.command`，浏览器会打开 http://127.0.0.1:4317/。
4. 停止服务用 `停止-macOS.command`。有运行任务时会拒绝停止，不会强制丢弃任务。

如果首次双击提示安全限制，请使用 macOS 正常的“隐私与安全性 → 仍要打开”流程；本包未经 Apple 签名或公证。如果文件执行权限未保留，可在终端进入文件夹运行 `bash 安装-macOS.command` / `bash 启动-macOS.command`。

## Windows 10 / 11

1. 双击 `安装-Windows.cmd`。依赖缺失时用系统 winget 安装 Node.js LTS、FFmpeg、Python 3.12；可能出现安装确认或管理员提示。
2. 如提示找不到 winget，请在 Microsoft Store 安装/更新“应用安装程序”，或从 https://nodejs.org/en/download、https://www.python.org/downloads/ 和 https://ffmpeg.org/download.html 安装依赖并加入 PATH，然后重新运行安装。
3. 双击 `启动-Windows.cmd`，浏览器会打开工作台。
4. 双击 `停止-Windows.cmd` 停止空闲服务。

首次安装后若提示 PATH 尚未刷新，关闭窗口并重新运行安装入口。Windows 入口仅在该 PowerShell 进程使用 Bypass 执行本包脚本，不修改系统执行策略。Windows 安装与浏览器唤起脚本已提供，本次在 macOS 上完成解压验证，尚未在 Windows 真机执行。

## CLI

无需全局 npm 安装。进入解压目录：

- macOS：`./cutpot-cli --help`；安装时可在 `~/.local/bin` 创建入口，现有同名入口不覆盖。
- Windows：`.\cutpot-cli.cmd --help`。
- 两者通用：`node bin/cutpot-cli.js --help`。

示例：`node bin/cutpot-cli.js export --burn-subtitles -o film.mp4`。

默认服务端口 4317；已被另一安装占用时，不会连接到错误的数据目录。可用 CLI `start --port 4318 --data /absolute/data` 启动独立服务，再访问对应端口。

## 数据、示例与配音

- 本包从空白工程启动，附带“乐乐”静态分镜示例，可点击“载入乐乐示例”。示例素材不代表已生成动态视频或真实儿童配音。
- 导入素材、工程、导出结果和字幕环境均保存在解压目录 `.cutpot/`。使用后不要删除该目录；移动整个安装文件夹前应停止服务，并备份数据。
- 本包不含原电脑的工程数据库、角色录音、密钥、日志、缓存和已有视频作品。软件存档与作品素材备份是两件事。
- GPT-SoVITS 仅包含接入代码，不包含 Python 推理模型或权重。需要在目标电脑独立部署模型服务，再为每个角色配置参考录音。参见 docs/tts.md。
- macOS 系统语音仅在 Mac 可用。Windows 需要配置 GPT-SoVITS 等可用服务；不会自动用其他声音替代。
- 字幕烧录使用独立 Python 环境与系统中文字体；Mac 自动找 Arial Unicode，Windows 自动找微软雅黑（C:\Windows\Fonts\msyh.ttc）。可用 CUTPOT_SUBTITLE_FONT 指定其他中文字体。
- 本包没有把 Node.js、FFmpeg、Python 虚拟环境跨电脑复制；安装脚本在目标电脑上配置正确平台的运行时。

## 核验与依赖来源

`release-manifest.json` 记录本包每个文件的 SHA-256。执行 `python3 scripts/verify-release.py .`（Windows 用 `py -3.12 scripts/verify-release.py .`）核验。

Node.js：https://nodejs.org/en/download
FFmpeg：https://ffmpeg.org/；Mac Homebrew：https://formulae.brew.sh/formula/ffmpeg
Python：https://www.python.org/downloads/；Pillow：https://pypi.org/project/Pillow/
Windows 包标识来自微软 winget-pkgs：OpenJS.NodeJS.LTS、Gyan.FFmpeg、Python.Python.3.12。

本包包含 CutPot 源代码与文档，便于后续维护；第三方运行时在目标机安装，遵循各自许可。
