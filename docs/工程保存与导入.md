# 工程保存与导入

01 分镜图创作、02 首尾帧视频、03 剪辑导出页面的顶部，均提供“新增项目”“保存工程”和“导入工程”。三个入口使用相同格式，可在任意页面保存、在另一个页面导入。

“新增项目”必须选择本机项目文件夹，并创建空白工程（新项目 ID）。画幅/帧率沿用当前输出设置。之后分镜、视频、素材、生成记录与导出都写入该文件夹下的 `.cutpot/`。有生成、导出或配音任务进行中时会拒绝新建。请先保存工程包以便恢复。

「保存工程」导出含素材的 `.cutpot.zip`（`GET /api/project-package`）。若提示「接口不存在」，说明本机服务仍是旧进程，请先停止再 `./start.sh` 重启。

## 工程包（推荐）

“保存工程”先提交当前页面的草稿，再下载 `.cutpot.zip` 工程包，内容包括：

- `project.json`：项目输出设置、完整脚本、画面风格、主体参考图、分镜及图片候选版本、视频候选版本与检查结论、分镜历史、剪辑时间轴、截取范围、速度、转场、字幕和音轨引用
- `media/`：当前工程实际引用到的图片、视频、音频文件
- 清单中每条素材带有 `id`、`name`、`type`、`sha256` 与相对路径 `file`，导入时按哈希写入本机素材库并重建对应关系

工程包可直接拷贝到其他电脑或其他 CutPot 项目导入，无需事先准备素材库。单包上限 8 GB。

## 旧版 JSON

仍兼容仅含引用的 `.cutpot.json` / 旧剪辑 JSON：保存素材 ID、名称与内容哈希，不包含媒体文件与本机路径。迁移时需先导入原媒体，再导入工程；相同内容可通过哈希重新关联。

## 导入规则

导入界面会列出项目名称和数量，要求确认替换；缺少素材、压缩包损坏或源文件失效时会明确报错，当前工程不变。

导入不会自动提交或恢复生成任务。已知任务编号作为历史记录保留；导入时原排队、运行或中断任务变成停止的历史记录。本机仍有生成、待查询、配音或导出任务时会阻止导入，防止覆盖正在工作的工程。

跨页面发生修改时，版本检查会拒绝覆盖，刷新后再导入。导入整份工程后清空剪辑撤销栈；需要恢复之前工作时，请先保存它的工程包。

## 接口

- `GET /api/project-package`：导出含素材的 zip
- `POST /api/project-package`：导入 zip
- `GET|POST /api/project-file`：读写轻量 JSON（兼容与 CLI）

`test/project-file.test.js` 覆盖格式兼容、哈希重新关联、工程包往返、缺失素材、非法关联、任务不自动执行、并发冲突及重启恢复。
