# 工程保存与导入

01 分镜图创作、02 首尾帧视频、03 剪辑导出页面的顶部，均提供“保存工程”和“导入工程”。三个入口使用相同格式，可在任意页面保存、在另一个页面导入。

“保存工程”先提交当前页面的草稿，再下载 `.cutpot.json`，包括项目输出设置、完整脚本、画面风格、主体参考图、分镜及图片候选版本、视频候选版本与检查结论、分镜历史、剪辑时间轴、截取范围、速度、转场、字幕和音轨引用。

工程文件保存素材 ID、名称与内容哈希，不包含媒体文件、登录凭据或本机文件路径。仍需保留本机素材库。迁移至另一台设备时，先导入原媒体，再导入工程；相同内容的素材可通过哈希重新关联。如果库中的源文件被移动，可重新上传该原素材以修复引用。导入界面会列出项目名称和数量，要求确认替换；缺少素材或文件已失效时会明确报错，当前工程不变。

导入不会自动提交或恢复生成任务。已知任务编号作为历史记录保留；导入时原排队、运行或中断任务变成停止的历史记录。本机仍有生成、待查询、配音或导出任务时会阻止导入，防止覆盖正在工作的工程。

兼容旧版只含剪辑数据的工程 JSON，同一项目的现有分镜数据保留。跨页面发生修改时，版本检查会拒绝覆盖，刷新后再导入。单个工程文件上限为 32 MB。导入整份工程后清空剪辑撤销栈；需要恢复之前工作时，请先保存它的工程文件。

后端通过 `/api/project-file` 提供统一导出和导入，导入同时检查剪辑与创作版本，并串行更新工程。`test/project-file.test.js` 覆盖格式兼容、哈希重新关联、缺失素材、非法关联、任务不自动执行、并发冲突及重启恢复。
