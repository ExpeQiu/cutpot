# 时间轴剪辑

在 `/editor` 打开剪辑工作台。V1 为连续的主画面轨道，接缝转场单独显示在其下方，旁白与音乐显示在 A1、A2。裁剪和变速会自动衔接后续片段。锁定限制镜头自身编辑及拖动排序，不固定它在成片中的绝对时间。

## 操作

- **截取**：拖动视频左、右边缘设置入出点；图片可拖右边缘改变停留时长。右侧可精确输入源入点、源出点或成片时长。时间轴上的位置以输出帧率对齐，源范围不能超过素材。
- **播放头**：点击或拖动标尺、拖动播放头定位；左右方向键移动一帧，按住 Shift 移动十帧。选择镜头后，标尺定位保持选中镜头，方便在精确位置截取或分割。
- **分割**：选中镜头，把播放头放到内部，按 S 或 Cmd/Ctrl+B。两段引用同一源素材，源范围连续，保留速度、原声和字幕。为保持转场长度，过于靠近转场的切点会提示移远或先移除转场。
- **截到播放头**：I 删除选中镜头在播放头之前的部分；O 删除之后的部分。至少保留一帧。
- **倍速**：选中视频，在右侧输入 0.25 至 4 倍，或点击预设。保留源范围，重新计算成片时长；向下取整到完整输出帧，最多损失不足一帧的源范围。预览与导出均保持原声音高。静态图片直接调整停留时长。
- **转场**：点击两段之间的“＋”或右侧转场选项，选择叠化、淡入黑场、淡入白场或向左擦除。支持调整时长和恢复硬切。转场最长五秒且不超过两侧较短镜头的一半；两段画面重叠，成片缩短相同长度，原声交叉淡化。裁短片段或变速后，转场会自动缩短至可用长度。
- **插入画面**：点击“插入画面”，选择素材、停留时长和插入位置。在镜头内部插入会先分割它，然后放入选定图片或视频。转场区间及锁定镜头内部不能插入。没有素材时可从弹窗导入。
- **吸附与缩放**：N 开关吸附；裁剪时吸附到播放头和其他镜头的边缘，按 Alt 暂时关闭。使用缩放滑块放大，或点击“适应”查看完整时间轴。
- **恢复**：Cmd/Ctrl+Z 撤销，Shift+Cmd/Ctrl+Z 或 Ctrl+Y 重做。每次拖动只计一次操作，恢复时保留选中片段和播放头位置。拖动中按 Esc 取消。

## 声音与字幕

旁白从成片开头播放，音乐循环至片尾。已有旁白在裁剪后长于成片时，页面显示提示，预览与导出在片尾截断；首次生成配音并设置旁白时仍校验配音长度。固定的旁白不跟随各镜头移动，修改叙事节奏后需重新检查对白与画面对应关系。

烧录字幕随镜头画面参与转场。独立 SRT 在下一镜头开始时切换字幕，不产生时间重叠。

## 工程与导出约定

保留工程版本 1，兼容旧工程。镜头新增 `speed`（默认 1）和 `transition`（默认 null）；`transition` 为当前镜头至下一镜头的 `{type,duration}`，最后一个镜头没有出场转场。`duration` 始终表示倍速后的成片时长，消耗的源时长为 `duration × speed`。

`public/timeline.js` 同时用于浏览器、后端校验、SRT 和 FFmpeg，统一按整数帧计算重叠与总时长。转场只渲染接缝窗口与剩余画面主体，再按时间顺序合并，避免每个接缝都重新编码整条时间轴。原素材不改写，视频导出继续保留工程与校验报告。

## 验收与回归

运行 `npm run check` 和 `npm test`；烧录字幕测试需要可用的 Pillow，可通过 `CUTPOT_SUBTITLE_PYTHON` 指定 Python。测试覆盖源范围越界、旧工程、速度上下限、连续分割、裁剪边界、转场长度约束、预览区间和 SRT 时间。真实 FFmpeg 测试检查快速与慢速、四种转场、画面像素、长旁白截断、总帧数和完整解码。浏览器验收应使用隔离数据目录，检查拖拽、分割、插入、撤销、重做、锁定与刷新保存。
